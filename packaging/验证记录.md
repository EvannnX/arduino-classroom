# Mac v1.0.1 验证记录

2026-10-17，分别解压 Apple-Silicon 与 Intel ZIP 后运行 `smoke-mac.mjs`。

- 测试目录包含空格与中文，使用空 HOME 和仅包含 macOS 系统目录的 PATH。
- Apple-Silicon 包通过实际 `.app` 的 shell 入口启动；Intel 包的 Node / CLI 在 Apple 芯片 Mac 的 Rosetta 下运行。
- 两个包均使用随包提供的 Node 22.23.3、Arduino CLI 1.5.1、AVR 1.8.8 与 Servo 1.3.0。
- 七节课示例均通过随包工具链的真实 Uno 编译：闪灯、旋律、舵机、计数、按住计时、双按钮、光线。
- 两个包均通过原生 SerialPort 端口枚举、SSE 初始连接事件、无效串口拒绝、重复启动复用服务与停止脚本检查。
- Vite 构建成功；启动脚本语法与 Node 启动程序语法检查通过。

未连接真实 Arduino，未验证实物上传、串口收发与电路行为。未在独立 Intel Mac 上测试，也未在带下载隔离标记的全新 Mac 上完成 Gatekeeper / Rosetta 安装流程。应用未进行 Apple Developer ID 签名与公证，首次运行可能需要在“隐私与安全性”中允许。
